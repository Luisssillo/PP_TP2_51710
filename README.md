## Descripción del Proyecto
Sistema de Gestión de Eventos Universitarios desarrollado en Java con IntelliJ IDEA.
El proyecto incluye:
* Manejo de colecciones y herencia (`Actividad`, `Charla`, `Taller`, `Curso`, `EventoUniversitario`).
* Métodos genéricos con `Class<T>` para filtrado de actividades por tipo.
* Métodos con wildcards (`List<? extends Actividad>`) para cálculo de costos de materiales.
* Serialización e I/O para persistencia de datos.
